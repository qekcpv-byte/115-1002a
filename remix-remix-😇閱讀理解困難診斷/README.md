## 🌟 核心理念與專案緣起

在數學教學現場，許多教師常感慨學生明明計算能力不弱，但一遇到長篇文字題、生活素養題或幾何圖文題就頻頻卡關。這往往不是數學運算能力的缺陷，而是**數學閱讀理解（Mathematical Reading Comprehension）**的認知負荷過重。  

本系統由**優履工作室研發**，以專業且溫暖的教學引導為出發點。我們依據認知心理學的 7 大困難來源，協助教師迅速診斷學生的閱讀盲點，並產出可立即落地的三維度教學法、20分鐘代課教案與診斷測驗卷，陪伴每位學生跨越數學文字的理解門檻。

## 🔍 7 大數學閱讀理解困難來源

依據數學閱讀與認知心理學研究，學生在面對數學題目時，最常遭遇以下 7 種閱讀理解障礙：

| 困難類型編號與名稱 | 核心認知特徵 | 教學現場常見迷思與具體範例 |
| :--- | :--- | :--- |
| **01. 忽略文本細節與圖形符號** | 容易忽略題幹關鍵限制字詞（至少、不超過、整數解）或幾何記號（直角標記、等長記號）。 | 把「恰有一個解」誤讀成「有一個解」，或漏看限制條件 $x > 0$。 |
| **02. 字詞的意義不清** | 混淆數學專業術語與日常用語，未能掌握幾何/代數詞彙嚴謹定義。 | 混淆「線段」與「直線」、「面積」與「周長」、「對稱軸」與「垂直平分線」。 |
| **03. 對生活情境與數學情境不理解** | 缺乏真實生活經驗（折扣比率、銀行利息、齒輪運轉），無法轉譯為數學算式。 | 題目敘述「打七五折」，學生不知是乘以 0.75 還是扣除 75%。 |
| **04. 缺乏適時使用閱讀策略** | 閱讀題目時未採取圈選關鍵字、草稿作圖、逐句轉譯或繪製表格等策略。 | 遇到幾何證明題只盯著文字看，不願在圖上標記已知條件，導致工作記憶超載。 |
| **05. 概念不清楚導致文本理解錯誤** | 底層數學概念薄弱，讀到專有名詞時提取了錯誤認知基模。 | 看到「成反比」直覺以為一方變大另一方就變小，忽略 $x \cdot y = k$ 本質。 |
| **06. 難以從文本中掌握重要資訊** | 面對長篇情境題無法過濾雜訊，抓不出已知條件與所求目標之因果關聯。 | 在長篇生活素養題的大段背景敘述中迷失方向，找不到列式核心變數。 |
| **07. 語法結構複雜導致理解障礙** | 句子過長、雙重否定、被動語態或倒裝修飾，造成工作記憶斷裂。 | 如「甲比乙的兩倍少 3」，容易誤列為 $2\text{甲} - 3 = \text{乙}$。 |

## 🚀 6 大專業診斷與研發流程

系統採循序漸進的階梯式架構，每完成一個階段均會停下進行對話引導與深入追問：

| 階段 (Stage) | 階段名稱 | 核心任務與交付成果 | 適用教學場景 |
| :--- | :--- | :--- | :--- |
| **Stage 1** | 7大困難來源映射 | 剖析特定單元觸發之閱讀障礙與學生真實思維障礙點 | 備課分析、診斷學生迷思 |
| **Stage 2** | 三個維度教學設計 | 歸納解碼層、整合層、策略層之具體課堂鷹架與提問句型 | 課程研發、公開授課設計 |
| **Stage 3** | 單元教學導向分類表 | 建立結構化矩陣：橫向比對子概念，縱向比對閱讀困難維度 | 全景盤點教學盲點 |
| **Stage 4** | 20分鐘代課教案 | 臨時代課或補救教學即開即用逐字稿、時間配比與板書規劃 | 代理代課、抽離式補救教學 |
| **Stage 5** | 閱讀障礙小考題 | 針對閱讀理解（非複雜計算）之診斷命題與誘答陷阱解析 | 課堂隨堂測驗、學力檢測 |
| **Stage 6** | Canvas 試卷排版板 | 雙模式（學生考卷 / 教師手冊）即時線上編輯、排版、Word 匯出 | 正式評量出題、診斷報告產出 |

## 🧭 波利亞 (George Pólya) 解題策略的深度融入

本系統在教學引導與教案設計中，全面貫徹波利亞四步驟思維：

📘 **步驟一：理解題目 (Understanding the Problem)**  
- 未知數是什麼？已知條件是什麼？限制條件是什麼？能否畫出一張圖來具象化題意？

📘 **步驟二：擬定計畫 (Devising a Plan)**  
- 以前見過類似的題目嗎？能否將複雜的文字先簡化為特例，找出變數間的關聯？

📘 **步驟三：執行計畫 (Carrying Out the Plan)**  
- 檢驗每個解題步驟，每一步是否都有幾何定理或代數邏輯作為推論依據？

📘 **步驟四：回顧反思 (Looking Back)**  
- 能否檢驗計算結果？有沒有更直觀的閱讀轉譯途徑？這個題目的文字結構對未來的解題有何啟發？

## 🛠️ 技術特點與架構

⚙️ **前端框架**：React 19 + TypeScript + Vite + Tailwind CSS。  
⚙️ **排版與動畫**：Lucide React + Motion 平滑過渡動畫。  
⚙️ **AI 核心推論**：Node.js Express + @google/genai (Gemini 2.5 系列模型多階段推論)。  
⚙️ **無依賴 Word 匯出**：原生 HTML/XML MIME 協議生成相容於 Microsoft Word 的 .doc 文件，保留完整版型與考卷排版。  
⚙️ **高對比度列印適配**：專屬 @media print 樣式，隱藏多餘按鈕，精準呈現學生考試用紙。
